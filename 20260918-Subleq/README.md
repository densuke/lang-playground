# Subleq を試す (2026-09-18)

「古今東西 プログラミング言語紹介」2026-09-18 回 (難解言語枠) の実験環境です。
動画: <https://www.youtube.com/watch?v=s3PrcOb8L8E>

## 使い方

```bash
./run.sh python3 subleq.py hello.sq   # 直接動かす
./run.sh                              # シェルに入る
./run.sh bash -s < demo.sh            # 動画で流した順に実行する
```

`container` (macOS 26 の Apple container) / `docker` / `podman` のいずれかがあれば動きます。

## 処理系について

**自作の最小インタプリタ** (`demo/subleq.py`) を使っています。標準ライブラリのみ。
命令が 1 つしかなく、動画でも「処理系は自作できます」と紹介したので、Thue 回と同じく
自作にしました。以下の一次情報を確認しながら実装しています。

- 仕様: <https://esolangs.org/wiki/Subleq>

確認した仕様のポイント:

- 命令は `a b c` の 3 つの数でひとつ。区切りは位置だけで決まる
- `b` 番地の値から `a` 番地の値を引き、結果を `b` 番地に書く
- 結果が 0 以下なら `c` 番地へ飛ぶ。そうでなければ次の命令へ進む
- `-1` 番地から引くと、**引いた値** (`a` 番地の値) を文字コードとする 1 文字が出力される
- 負の番地へ飛ぶと停止する

本実装の簡略化:

- 出力の命令 (`b` が `-1`) のあとは、`c` を見ずに次の命令へ進みます。仕様の例では
  `c` に次の番地を書いているので、同梱のデモでは違いは出ません
- 入力 (`a` が `-1`) には対応していません。使うとエラーで止まります
- メモリの外へ進んだときも停止します

自作の処理系は静かに間違うことがあります。そこで、Esolang wiki の記事に載っている
例 (`demo/hi.sq`、動画の「Hello, world の冒頭」と同じ数列) を動かし、記事に書かれた
とおり `Hi` が出ることをデモの中で確かめています。

実は、動画の検証に使った最初の処理系は出力の符号を反転させていました。検証用の
Hello, world も文字コードを負の値で置いていたため、両方が間違ったまま噛み合い、
正しく `Hello, world!` が出ていました。その処理系で Esolang wiki の例を動かすと
文字化けします。この実験環境では仕様どおり**符号を反転しない**形に直し、
`hello.sq` も文字コードを正の値で置き直しています。

## 入っているもの

| ファイル | 内容 |
|---|---|
| `demo/subleq.py` | 自作インタプリタ本体 |
| `demo/hi.sq` | Esolang wiki の記事の例。`H` と `i` を出して止まる |
| `demo/add.sq` | 動画で紹介した「引き算だけで足し算」。3 + 4 を計算して `7` を出す |
| `demo/hello.sq` | `Hello, world!` と改行を 1 文字ずつ出す |

ソースは数を空白かカンマで区切って並べます。`#` から行末まではコメントとして読み飛ばします
(コメントはこの実験環境の便宜で、Subleq の仕様にはありません)。

## 実行結果

```
$ cat hi.sq
# Esolang wiki の Subleq の記事に載っている例。H と i を出して止まる
9 -1 3
10 -1 6
0 0 -1
72 105 0

$ python3 subleq.py hi.sq
Hi

$ cat add.sq
# 3 + 4 を引き算だけで計算して、結果を 1 文字で出す
# 18 番地 = 3、19 番地 = 4 の代わりに文字 '4' (52)、20 番地 = 作業用、21 番地 = 改行
20 20 3    # 作業用 = 0 (自分から自分を引く)
18 20 6    # 作業用 = 0 - 3 = -3
20 19 9    # 19 番地 = 52 - (-3) = 55 = 文字 '7'
19 -1 12   # 19 番地を 1 文字出力する
21 -1 15   # 改行を出力する
20 20 -1   # 作業用 = 0 なので -1 番地へ飛んで停止
3 52 0 10

$ python3 subleq.py add.sq
7

$ cat hello.sq
# Hello, world! と改行を出す。1 行目から順に 1 文字ずつ出力して、最後に停止する
45 -1 3
46 -1 6
47 -1 9
48 -1 12
49 -1 15
50 -1 18
51 -1 21
52 -1 24
53 -1 27
54 -1 30
55 -1 33
56 -1 36
57 -1 39
58 -1 42
0 0 -1
72 101 108 108 111 44 32 119 111 114 108 100 33 10

$ python3 subleq.py hello.sq

```

`hi.sq` は出力の最後に改行を出さないので、`demo.sh` の側で表示をそろえるために
改行を足しています。

`add.sq` は動画の手順そのままです。作業用の場所を 0 にし、そこから 3 を引いて -3 を作り、
それを引くことで 3 が足されます。4 を文字 `'4'` (文字コード 52) として置いておくと、
足した結果の 55 がそのまま文字 `'7'` になるので、1 文字の出力で答えを見せられます。

## つまずきやすい点

**命令の区切りは位置だけです。** 数を 1 個書き落とすと、それ以降の命令がすべてずれて
別のプログラムになります。エラーにはなりません。

**データとプログラムが同じメモリに並んでいます。** `hi.sq` の最後の `0 0 -1` は、
0 番地 (最初の命令の `9`) を 0 に書き換えてから停止しています。ここでは停止する直前なので
害はありませんが、書き換えた番地をあとで命令として使うと別の動きになります。
番地の割り当ては慎重に決めてください。

**出力の文字コードは `a` 番地の値そのものです。** 符号を反転させる処理系と、負の文字コードを
置いたプログラムを組み合わせると、両方が間違っていても正しく見えてしまいます。
仕様の例 (`hi.sq`) でも確かめてください。
