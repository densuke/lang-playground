# Grass を試す (2026-10-02)

「古今東西 プログラミング言語紹介」2026-10-02 回の実験環境です。金曜は Esolang の枠です。

## 使い方

```bash
./run.sh grass /work/helloworld.grass   # 草を実行する
./run.sh                                # シェルに入る
./run.sh bash -s < demo.sh              # 動画で流した順に実行する
```

`container` (macOS 26 の Apple container) / `docker` / `podman` のいずれかがあれば動きます。

## 処理系について

**作者 UENO Katsuhiro 氏本人による Ruby 実装 `grass.rb`** (2007-10-02 版) を同梱しています。
BSD ライセンスなので、著作権表示を残したまま再配布できます。

自分で書いた処理系は静かに間違います。Grass は結果が「文字が出る / 出ない」だけなので、
間違っていても気づけません。だから公式実装をそのまま使っています。

作者のサイト (`www.blue.sky.or.jp/grass/`) は 2025 年ごろから繋がらなくなっています。
`grass.rb` は [TryItOnline/grass](https://github.com/TryItOnline/grass) のミラーから取りました。

## 言語の中身

**使う文字は `w` `W` `v` の 3 つだけ**です。それ以外は全部コメントとして捨てられます。

| 書き方 | 意味 |
|---|---|
| 先頭の `w` の並び | 関数の引数の数 (ラムダ抽象) |
| `W` の並びと `w` の並びの組 | 関数適用。並びの長さが「上から何番目か」 |
| `v` | 定義の区切り |

最初から使えるものが 4 つあります。上から順に `Out` (1 文字出力)、`Succ` (文字コード +1)、
文字 `w` そのもの、`In` (1 文字入力) です。**数も文字列も無く、あるのは関数だけ**という
ラムダ計算そのものの構造をしています。

## 入っているもの

| ファイル | 内容 |
|---|---|
| `demo/w.grass` | `wWWwwww` の 7 文字。`w` を 1 文字出力する最小のプログラム |
| `demo/succ.grass` | `wWWWwwwwWWWw`。`Succ` で 1 進めて `x` を出力する |
| `demo/helloworld.grass` | `Hello,world!` を出力する。**1000 文字を超える草原** |

## 実行結果

```
$ ./run.sh grass /work/w.grass
w

$ ./run.sh grass /work/succ.grass
x

$ ./run.sh grass /work/helloworld.grass
Hello,world!
```

`w.grass` の 7 文字を分解するとこうなります。

```
w      引数 1 個の関数を作る
WW     env の上から 2 番目 (= Out) を
wwww   env の上から 4 番目 (= 文字 w) に適用する
```

これだけで `w` が 1 文字出ます。`succ.grass` は `Succ` を挟んで `w` の次の文字を出しています。

## つまずきやすい点

**`w` より前の文字は全部捨てられます。** ファイルの先頭に日本語のコメントを書いても
構いません。ただし `w` `W` `v` は拾われるので、コメントに含めないでください。

**全角の `ｗ` `Ｗ` `ｖ` も同じ文字として扱われます。** 掲示板から貼れるようにするためです。

**大文字と小文字を間違えると別のプログラムになります。** エラーにはならず、黙って
違うものが出ます。

**入力した文字の「比較」は期待どおりに動きません。** 読んで出力し直すだけなら動きます
(`echo a` を流すと `a` が出ます)。ただし実装は Ruby 1.8 時代のもので、`$stdin.getc` が
文字コードを返る前提です。いまの Ruby では文字列が返るため、読んだ文字を比べると
常に偽になります。**入力を見て分岐するプログラムは避けてください。**
