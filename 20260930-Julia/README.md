# Julia を試す (2026-09-30)

「古今東西 プログラミング言語紹介」2026-09-30 回の実験環境です。

## 使い方

```bash
./run.sh                                # 対話環境 (julia) に入る
./run.sh julia /work/dispatch.jl        # 直接動かす
./run.sh bash -s < demo.sh              # 動画で流した順に実行する
```

`container` (macOS 26 の Apple container) / `docker` / `podman` のいずれかがあれば動きます。
Julia は Debian のパッケージから外れているので、公式イメージ (`julia:1`) を使っています。

## 処理系について

公式の **Julia 1.13.0** です。書くときは Python に似ていますが、実行の直前に
引数の型ごとの機械語へコンパイルされます。

```
$ ./run.sh
julia> f(x) = x + 1
julia> f(1), f(1.5)
(2, 2.5)
julia> f(1) isa Int, f(1.5) isa Float64
(true, true)
```

**最初の呼び出しだけ遅い**のはこのためです。起動直後の 1 回目を測って「遅い」と
判断しないでください。

## 入っているもの

| ファイル | 内容 |
|---|---|
| `demo/basics.jl` | Hello World・フィボナッチ・行列とブロードキャスト (`.`) |
| `demo/dispatch.jl` | **多重ディスパッチ。** 引数の型の組で呼ぶ実装が決まる |

`extend.jl` は `Money` 型を定義して `+` に実装を 1 つ足しただけです。それだけで
**自分では何も書いていない `sum` が通ります。** ライブラリの作者が `Money` を
知らなくても組み合わせが効くのが、多重ディスパッチの狙いです。

## つまずきやすい点

**配列の添字が 1 から始まります。** 数式に寄せた設計なので、`A[1]` が先頭です。

**`.` の有無で意味が変わります。** `A * B` は行列積、`A .* B` は要素ごとの積です。
`sqrt(x)` はスカラー用で、配列には `sqrt.(x)` と書きます。

**関数に型を書かないほうが速いことがあります。** `f(x::Float64)` と絞ると他の型で
呼べなくなるだけで、速くはなりません。型は制約を表すために書きます。

**グローバル変数は遅いです。** 計測するときは処理を関数の中に入れてください。
